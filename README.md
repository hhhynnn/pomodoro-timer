# 番茄钟

在线使用：**https://hhhynnn.github.io/pomodoro-timer/**

一个中文静态番茄钟，打开网页即可使用，无需安装或注册。

- 专注、短休息、长休息。
- 点击数字输入时间，也可以拖动、滚轮或滑块调整。
- 开始、暂停、继续、停止；全屏和夜间模式。
- 自定义时长与提示音，保存专注次数和实际专注时间。

## 数据保存

设置和计时记录只保存在当前浏览器的本地存储中，不上传到服务器。不同设备、浏览器及网站地址之间不自动同步。

关闭网页后不会响铃；电脑休眠时不能保证准时提醒。

## 本地使用

下载 `index.html` 并用浏览器打开即可，页面包含全部样式、逻辑和合成提示音，无第三方运行库或外部资源请求。

## 发布

使用 GitHub Pages，发布源为 `main` 分支的根目录。`.nojekyll` 用来直接发布静态文件。

更新 `index.html` 后提交到 `main`，GitHub Pages 会自动重新发布。
